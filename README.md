# FitLife
Это проект для локального развертования для подсчета индекса массы тела пользователя и подсчета нормы воды в сутки
Программа принимает на вход данные пользователя, такие как: имя, возраст, вес и рост. Далее происходят вычисления и пользователю через экран терминала
выводится отчет для этого пользователя. Отчет состоит из заголовка (для кого отчет), индекса массы тела, рекомендуемая норма воды в сутки и добрых пожеланий.

Для локального развертывания этого проекта понадобиться клонировать этот репозиторий с платформы GitHub на свой пк. Затем при помощи редактора кода или IDE открыть директорию этого проекта. В терминале, находясмь в директории проекта, активировать окружение, установить зависимости проекта из файла requirements.txt. И затем запустить работу файла fit_life.py
